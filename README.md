# Achyuth A R

My personal site: who I am, who I want to be, and how I see myself.

Plain HTML, Tailwind (CDN) and a little JavaScript. No build step.

## Run locally
Open `index.html` in a browser.

## Add photos
Put images in `images/` and set their paths in the `IMAGES` block at the bottom of `index.html`.

## Deploy
Hosted with GitHub Pages from the `main` branch, root folder.
